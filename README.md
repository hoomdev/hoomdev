Plataforma multiempresa para emisión, firma, transmisión, almacenamiento, contingencia, invalidación y reportes de documentos tributarios electrónicos. APIs REST, PostgreSQL, Docker/Linux e integración con servicios gubernamentales.

Módulos, indicadores, evidencias, APIs, dashboards y funcionalidades en tiempo real para una plataforma usada por instituciones de Centroamérica y República Dominicana (SE-COMISCA / SICA).

**[hoomAI](https://github.com/hoomdev/hoomai) — AI Software Engineering Orchestration**
Proyecto open-source para explorar roles especializados de IA, orquestación de agentes y flujos de planificación, implementación, revisión y testing con modelos en la nube y locales.

**Plataformas empresariales y SaaS**
Soluciones de ventas, inventario, clientes, pagos, distribución, e-commerce y reporting para operaciones multiempresa, con foco en arquitectura mantenible e integraciones.

- **Ownership de punta a punta:** requerimientos, arquitectura, desarrollo, despliegue y soporte en producción.
